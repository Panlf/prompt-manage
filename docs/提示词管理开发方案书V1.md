## 1. 软件功能总览（当前完整基线）

PromptHub 是一款基于 **Electrobun + SQLite** 的**本地优先**提示词管理桌面应用（Windows 优先，支持 mac/linux 打包），无任何云端依赖，除用户自行配置的 LLM API 外不发起任何网络请求。

| 模块 | 功能明细 |
|------|----------|
| **总览（仪表盘）** | 四张统计卡（场景数/提示词数/收藏数/累计使用）点击跳转；"我的收藏"速览（最多 6 条）；"最近使用"列表（最多 8 条）；空态引导创建场景 |
| **使用场景** | 场景 CRUD；场景标签（增删改、重命名、删除联动、点击筛选）；场景名称/描述实时搜索；删除场景有明示级联后果的确认弹窗 |
| **提示词管理** | 提示词 CRUD；**提示词级标签**（逗号分隔输入、大小写不敏感去重、列表/卡片 pills 展示）；**版本历史**（内容变更前自动快照、查看/恢复/删除、删除后自动重编号）；**收藏**（列表与详情页星标切换、就地更新）；删除为软删除进回收站 |
| **变量模板引擎** | 自动解析 `{{变量名}}`（去重保序、支持中文变量名、纯数字视为普通文本）；详情页变量填充面板（逐变量输入、实时预览、未填保留 `{{原名}}`）；"复制填充结果"记一次使用 |
| **全部提示词** | 跨场景聚合视图；三种排序（最近使用/最常用/最近更新）；按提示词标签过滤；"⭐ 仅收藏"过滤（收藏变动即时联动刷新）；**懒加载分页**（首屏 6 条，滚动到底自动续载，加载失败 2s 自动重试；页头计数恒为筛选匹配的总条数）；列表局部刷新不闪屏 |
| **收藏视图** | 按最近使用排序的全部收藏列表，支持复制/进入详情/取消收藏 |
| **回收站** | 软删除提示词列表（含所属场景与删除时间）；单条恢复/彻底删除；清空回收站；场景删除会物理级联（含回收站内），弹窗明示 |
| **命令面板（⌘K）** | `Ctrl/⌘+K` 唤起 Spotlight 风格面板；同时搜索场景名/描述 + 提示词标题/内容/场景标签/提示词标签；关键词高亮；↑↓/Enter/Esc 全键盘操作；空态显示最近使用 5 条；输入防抖 + 竞态守卫 |
| **预检** | 文本生成 / 图片生成 / 文本优化三种类型；变量未填齐时阻止提交；单模型执行、结果单框展示（新结果覆盖旧结果）；文本可复制、图片可下载、超长输出截断展示 |
| **模型设置** | 多 LLM 配置（DeepSeek / MiMo / Ollama / 自定义 OpenAI 兼容）；连通测试（60s 硬超时 + 中文错误提示）；设为默认模型；API Key 不随导出泄露 |
| **数据管理** | JSON 全量导出（系统文件夹选择器，不含 API Key）；导入覆盖（旧版本备份兼容导入、约束错误友好提示、事务回滚保护）；数据目录迁移（WAL checkpoint 方案，失败不影响原库）；目录校验；便携 config.json 外置配置 |
| **外观与窗口** | 自定义无边框标题栏（拖拽/双击最大化/最小化/关闭）；页面配色主题（标题栏调色板选择，持久化到数据库）；深浅色自动适配；页面切换过渡动效 |
| **快捷键** | `Ctrl/⌘+K` 全局搜索；`Ctrl/⌘+S` 保存提示词（仅详情页生效）；`Esc` 关闭弹层/面板 |

**已移除功能**（本轮调整，详见第三部分 §9）："AI 生成提示词"（新建弹窗内的 AI 生成区块及后端链路）、提示词"手动/AI"来源标识（徽标与筛选）。

# 第一部分 产品方案

## 1. 背景与产品定位

### 1.1 现状
PromptHub v1.0.0 发布时的能力基线：

| 模块 | v1.0.0 已有能力 |
|------|----------|
| 场景管理 | 场景 CRUD、标签（增删改）、标签筛选、名称/描述搜索 |
| 提示词管理 | 提示词 CRUD、AI 生成提示词（**已于当前基线移除**）、版本历史（自动快照 + 恢复） |
| 预检 | 文本生成 / 图片生成 / 文本优化，运行历史留存 |
| 模型设置 | 多 LLM 配置（DeepSeek / MiMo / Ollama / 自定义 OpenAI 兼容）、连通测试、默认模型 |
| 数据管理 | JSON 全量导出/导入、数据目录迁移 |

### 1.2 问题
用户拿到 v1.0 后的核心抱怨（结合同类产品公开评测与社区反馈推断）：
1. **存了之后用得少**——从"找到"到"用上"的路径太长：要进场景 → 找提示词 → 手动选中复制 → 手动替换里面的占位内容。
2. **找不到**——提示词分散在各场景里，没有跨场景的全局搜索；常用提示词没有收藏置顶。
3. **不敢删**——删除是硬删除，误删即丢失，无回收站。
4. **不知道哪些好用**——没有使用统计，无法按"最常用/最近用"组织。

## 2. 竞品调研结论（高热度功能挖掘）

调研对象：PromptBox、AIPRM、Snack Prompt、AI Gist、PromptKit、Prompt Minder、PromptHub（企业版）、Langfuse、Quicker 常用语工具箱。

### 2.1 热度矩阵（★ 越多代表在该类产品中出现越普遍、口碑越好）

| 功能 | 热度 | 代表产品 | 对本地单机版的适配结论 |
|------|:---:|----------|------------------------|
| **模板变量 `{{变量}}`**（自动检测→填空→生成） | ★★★★★ | PromptBox（自动检测变量是其核心卖点）、AI Gist（Jinja 模板）、Langfuse/PostHog（template variables） | ✅ P0 并入，是"从存到用"的关键一步 |
| **一键复制到剪贴板** | ★★★★★ | PromptKit（快速复制）、AI Gist、Quicker | ✅ P0 并入，复用/复制次数同时作为使用统计信号 |
| **收藏 / 快速访问** | ★★★★☆ | AIPRM（Favorite 列表为付费点）、几乎所有工具 | ✅ P0 并入 |
| **全局搜索 / 命令面板（⌘K）** | ★★★★☆ | Raycast/Spotlight 交互范式，PromptKit 菜单栏搜索 | ✅ P0 并入，Spotlight 风格完全契合苹果化定位 |
| **使用统计 / 最近使用** | ★★★☆☆ | AI Gist（自动记录使用历史） | ✅ P0 并入（复制即视为一次使用） |
| **回收站 / 软删除** | ★★★☆☆ | 通用桌面软件标配 | ✅ P1 并入，消除"不敢删" |
| **键盘快捷键** | ★★★☆☆ | 效率工具标配（⌘K / ⌘S） | ✅ P1 并入 |
| **仪表盘总览** | ★★☆☆☆ | 企业级工具（PromptHub/Langfuse）有 dashboard | ✅ P1 并入（轻量统计 + 快捷入口） |
| 社区发现 / 分享 / Remix | ★★★★☆ | Snack Prompt、AIPRM（2M+ 用户） | ⏸ 暂缓（需服务端，与本地优先冲突；规划内置"精选模板库"离线包替代） |
| 团队协作 / 云同步 | ★★★☆☆ | PromptHub、Prompt Minder | ⏸ 暂缓（同上） |
| 版本 Diff 对比视图 | ★★☆☆☆ | PromptLayer、企业 PromptHub | ⏸ 暂缓（已有版本快照，diff 视图后续叠加）→ 后续候选 |
| 多模型并行对比测试 | ★★☆☆☆ | Prompt Minder | ⏸ 暂缓（预检已支持单模型，对比视图后续叠加）→ 后续候选 |

### 2.2 结论
本地单机场景下，用户价值最高、且与"苹果化"体验最契合的一组功能是：
**变量模板 + 一键复制 + 收藏 + 全局搜索（⌘K）+ 使用统计 + 回收站 + 快捷键**。
它们共同构成"**存 → 找 → 填 → 复制 → 统计**"的完整使用闭环。——该闭环已在当前基线全部交付。

## 4. 功能需求

### 4.1 P0 — 变量模板系统
**FR-1 变量解析**：系统自动解析提示词内容中所有 `{{变量名}}` 占位符（去重、保序）。变量名仅支持中文、字母、数字、下划线、连字符，其余视为普通文本。
**FR-2 变量填写面板**：提示词详情页右侧新增"变量填充"区。检测到变量时逐个渲染输入框（默认值为空）；未检测到变量时显示"此提示词未包含变量"。
**FR-3 实时预览**：填写值后，实时渲染替换后的完整提示词预览（只读，等宽字体）。
**FR-4 复制即使用**：预览区提供"复制结果"按钮——将替换后的文本复制到剪贴板，并记一次使用（见 FR-8）。未填的变量保留 `{{原名}}` 原样。
**验收标准**：
- `你好{{名字}}，我是{{职业}}` 解析出 `["名字","职业"]`；填写后预览为替换结果。
- 嵌套大括号（如 `{{{x}}}`）按最内层 `{{x}}` 处理时行为可预期且不崩溃。
- 复制后剪贴板内容与预览逐字节一致；使用计数 +1。

### 4.2 P0 — 一键复制
**FR-5**：提示词列表卡片、详情页、搜索结果、收藏列表均提供复制按钮，一键复制**原始内容**（不替换变量），同样记一次使用。
**FR-6**：复制必须有可见反馈（按钮短暂变为"已复制"✓ + Toast），并在按钮上保留 1.5s 成功态。

### 4.3 P0 — 收藏
**FR-7**：提示词可收藏/取消收藏（星形图标，列表与详情页均可操作）。新增"收藏"侧边栏视图：按最近使用排序展示全部收藏提示词，支持直接复制/点击进入详情。

### 4.4 P0 — 使用统计
**FR-8**：每次复制（原始或变量填充结果）记一次使用：`use_count + 1`、`last_used_at = now`。
**FR-9**：新增"全部提示词"视图：跨场景聚合，支持三种排序（最近使用 / 使用次数 / 更新时间），显示使用次数徽标，支持按提示词标签、收藏状态过滤。
> 调整说明：原设计的"来源（AI/手动）过滤"已随 AI 生成功能一并移除（见第三部分 §9）；标签过滤为 v1.0.2 增量能力。

### 4.5 P0 — 全局搜索（命令面板）
**FR-10**：`Ctrl+K`（mac 为 `⌘K`）唤起居中悬浮命令面板（Spotlight 风格：毛玻璃、大搜索框）。
**FR-11**：同时搜索场景名/描述与提示词标题/内容/标签，实时（输入防抖 150ms）返回，分组展示"场景 / 提示词"，关键词高亮。
**FR-12**：键盘完整可操作：↑↓ 选择、Enter 打开（场景→场景详情；提示词→提示词详情）、Esc 关闭。空态显示最近使用的 5 条提示词。
**验收标准**：任意页面可唤起；搜索"不存在内容"显示无结果态；Enter 跳转正确。

### 4.6 P1 — 回收站
**FR-13**：删除提示词为软删除（进入回收站），侧边栏新增"回收站"视图，显示删除时间与所属场景。
**FR-14**：回收站支持单条恢复（回到原场景）与单条彻底删除；支持"清空回收站"。
**FR-15**：删除场景仍为物理删除（级联删除其提示词，含回收站内），确认弹窗文案必须明示该后果。
**验收标准**：软删除的提示词不再出现在任何正常视图与全局搜索中；恢复后数据完整（含收藏、使用计数、版本历史、标签）。

### 4.7 P1 — 快捷键
**FR-16**：`Ctrl/⌘+K` 全局搜索；`Ctrl/⌘+S` 保存当前提示词编辑（仅提示词详情页生效）；`Esc` 关闭弹层/面板。
**FR-17**：命令面板底部常驻快捷键提示条。

### 4.8 P1 — 仪表盘总览
**FR-18**：新增"总览"首页：四张统计卡（场景数、提示词数、收藏数、累计使用次数）+ "最近使用"列表（最多 8 条）+ "我的收藏"速览（最多 6 条），均可点击跳转。

### 4.9 重构需求（技术侧同步交付）
**FR-19**：原生 `confirm()` 全部替换为苹果风格确认对话框组件（危险操作红色按钮、默认聚焦取消）。
**FR-20**：数据库增加轻量迁移机制（按列存在性检测补列），保证老用户数据无损升级。
**FR-21**：变量解析逻辑置于 `src/shared/`，前后端共用，可单元测试。

### 4.10 v1.0.2 ~ v1.1.0 增量需求汇总
- **提示词级标签**（v1.0.2）：与场景标签完全独立的第二套标签体系，用于区分同场景下不同方向（正式/口语化/平台风格等）；支持列表展示、过滤、⌘K 搜索命中。
- **导航体验**（v1.0.2）：视图切换淡出淡入过渡；"全部提示词"排序/筛选切换仅局部刷新列表。
- **外置数据目录配置**（v1.1.0）：便携版 `config.json`（与 exe 同目录）指定数据目录，升级覆盖解压不丢失。
- **页面配色主题**（v1.1.0）：标题栏调色板按钮切换配色，持久化到数据库。
- **窗口健壮性**（v1.1.0）：Windows 无边框窗口最大化后输入命中区域重算（防点击穿透）。

### 4.11 后续规划（本期不开发）
视口虚拟滚动（离屏节点回收；懒加载分页已先行落地）、版本 Diff 对比、多模型并行对比预检、内置精选模板库（离线社区包）、云同步/团队协作、菜单栏/托盘快捷面板、自动备份。

# 第二部分 设计规范（Apple 风格）

## 2. 组件级设计

### 2.1 星形收藏（Favorite Star）
- 空态：描边星形，`--text-tertiary`；悬浮加深。
- 已收藏：实心星形，`#ff9f0a`（Apple 橙黄），无底板。

### 2.2 复制按钮（Copy Chip）
- 列表卡片：胶囊小按钮 `⧉ 复制`，`--bg-secondary` 底。点击 → 1.5s 内变为绿色 `✓ 已复制`（`--success` 文字 + `--success-soft` 底）→ 还原。同时 Toast 通知。
- 详情页变量面板：主按钮"复制填充结果"，同反馈逻辑。

### 2.3 命令面板（⌘K / Spotlight 风格）
- 居中悬浮，距顶 18vh，宽 640px，圆角 20px，`--shadow-elevated`，背景毛玻璃遮罩 `blur(8px)` + `rgba(0,0,0,0.32)`。

### 2.4 苹果风格确认对话框（替代原生 confirm）

## 2. 数据库

### 2.1 数据目录解析优先级（`db.ts`，`resolveDataDir` 为可单测纯函数）

```
1. PM_DATA_DIR 环境变量        （仅自动化测试注入）
2. 便携配置 bin/config.json    （与 PromptHub.exe 同目录，{"dataDir": "D:\\..."}，兼容旧键 customDataDir）
3. AppData config.json         （应用内"数据管理→迁移"维护，升级天然保留）
4. 默认 %LOCALAPPDATA%\promptmanage.app\stable
```

- `getConfigSource()` 返回当前生效来源（portable/appdata），`getDataPath` RPC 透出，数据管理页显示提示。
- `migrateDataDir` 把新路径写回**生效中**的配置文件（便携优先）；Windows 下路径比较不区分大小写，防止"迁移到自己"误判。
- 升级姿势：**覆盖解压**——发布 zip 只含 `config.example.json` 模板，不含 `config.json`，解压永不覆盖用户配置。

### 2.2 prompts 表结构演进（v1.0.0 → v1.0.1 自动迁移）
`PRAGMA table_info` 检测后 `ALTER TABLE ADD COLUMN` 补列（模块加载时执行一次，幂等）：

| 列 | 类型 | 说明 |
|----|------|------|
| `is_favorite` | INTEGER NOT NULL DEFAULT 0 | 收藏星标 |
| `use_count` | INTEGER NOT NULL DEFAULT 0 | 复制即使用，累计计数 |
| `last_used_at` | TEXT | 最近一次使用时间 |
| `deleted_at` | TEXT NULL | 软删除时间戳；NULL=正常 |

**遗留列说明**（本轮调整）：`source`（默认 `'manual'`）与 `model_name` 两列**保留在 schema 中但代码不再读写**——新建提示词不再写入来源，UI 不再展示；旧库数据无需迁移，导入备份时这两个字段直接忽略。保留列是为了零迁移风险的平滑过渡。

### 2.3 提示词级标签（v1.0.2）
| 表 | 说明 |
|----|------|
| `prompt_tags` | 提示词标签池（id, name UNIQUE, created_at） |
| `prompt_tag_map` | 提示词↔标签多对多关联（双外键 ON DELETE CASCADE） |

- 与场景标签（`tags` + `scenario_tags`）**完全独立**。
- `Prompt.tags: string[]` 由查询填充（非表列）；批量加载 `loadPromptTags(ids)` **按 500 条分块**查询（防 SQLite 变量数上限），避免 N+1。
- `setPromptTags` 事务内删旧插新，按 `LOWER(name)` 大小写不敏感去重。
- 中文标签排序按 UTF-8 码位（SQLite ORDER BY 默认行为），非拼音序。

### 2.4 查询层关键函数
| 函数 | 说明 |
|------|------|
| `trashPrompt / restorePrompt / purgePrompt / emptyTrash` | 软删除 / 恢复 / 彻底删除 / 清空 |
| `getTrashedPrompts` | 回收站列表（JOIN 场景名） |
| `togglePromptFavorite` | 收藏切换（`1 - is_favorite` 原子翻转） |
| `recordPromptUse` | `use_count+1`、`last_used_at=now` |
| `getFavoritePrompts / getAllPrompts(sort,{favorite,tag,limit?,offset?}) / getRecentPrompts` | 跨场景视图查询；`getAllPrompts` 支持 LIMIT/OFFSET 分页并返回 `{ items, total }`（total=筛选匹配总数，与分页无关），排序均以 `id DESC` 收尾保证分页顺序确定 |
| `getDashboardStats` | 总览四项统计 |
| `searchAll` | 全局搜索：场景名/描述 + 提示词标题/内容/标签（LIKE ESCAPE 防 `%_` 通配注入，各限 6 条） |
| `deletePromptVersion` | 删除历史版本并将剩余版本紧凑重编号 |
| `createPrompt / updatePrompt` | **后端校验标题非空**（trim 后） |
| `importData` | 单事务全量覆盖导入；INSERT 语句循环外预编译（万条级性能）；v1.0.0/v1.0.1 旧备份兼容，`source`/`model_name` 字段忽略 |

### 2.5 外键语义（回收站边界）
`prompts.scenario_id → scenarios.id ON DELETE CASCADE`（`PRAGMA foreign_keys = ON`）：**删除场景会物理级联删除其提示词（含回收站内）**。前端场景删除确认框已明示该后果。

## 3. RPC 接口（bun/index.ts + mainview/core.ts 双端类型同步）

- 请求超时上限 10 分钟（原生文件夹选择对话框与 LLM 长请求需要）。
- 当前接口全集：场景 5 + 标签 3 + 提示词 12（含 trash/restore/purge/emptyTrash/getTrashedPrompts/toggleFavorite/recordUse）+ 提示词标签 1 + 收藏使用 3 + 版本 3 + 预检 2 + 模型配置 6 + 数据管理 6 + 窗口控制 6 + UI 偏好 2。
- 本轮签名变更：
  - `createPrompt`：`{ scenario_id, title, content, tags? }`（`source`/`model_name` 参数已移除）
  - `getAllPrompts`：`{ sort, favorite?, tag?, limit?, offset? }` → `{ items, total }`（新增分页参数与总数；`source` 筛选参数已移除）
  - `generatePromptAI`：**整体移除**（前端声明、后端 schema、handler、`llm.ts` 实现四处同步删除）
- `importData` handler 对约束错误做友好化翻译（外键缺失 / 编号重复 → 中文提示，明示已回滚）。

## 4. 前端实现要点

### 4.1 变量引擎（src/shared/types.ts）
- `extractVariables(content)`：正则 `\{\{([^{}]*)\}\}/g` 提取，变量名限中英数字下划线连字符且非纯数字；去重保序。
- `fillVariables(content, values)`：**长名优先替换**（避免 `{{lang}}` 吞掉 `{{language}}`）；`split().join()` 全量替换（避免 `$` 序列陷阱）；未填变量保留 `{{原名}}`。
- 三重大括号 `{{{x}}}` 匹配内层 `{{x}}`，外层保留为字面文本。

### 4.2 状态与导航（core.ts）
- 9 个视图；`openPrompt(id, scenarioId, origin)` 记录来源视图，用于侧栏高亮与返回目标。
- `copyTextToClipboard`：Clipboard API → 隐藏 textarea `execCommand` 双保险。
- `copyPromptAndRecord`：复制成功后异步 `recordPromptUse`，1200ms 防抖（快速重复复制同一条只记一次）。
- `showConfirm`：iOS Alert 风格，互斥不堆叠，默认焦点取消，Enter 激活焦点按钮。
- `isMacPlatform()`：优先 `userAgentData.platform`，回退 `navigator.platform`（统一封装）。
- `formatDate`：对 Invalid Date 显式检查返回原字符串（防"Invalid Date"上屏）。
- 全局 `unhandledrejection` 兜底 Toast。

### 4.3 共享组件（components.ts）
- `ICONS` 内联 SVG；`promptRowHtml` / `bindPromptRows`（跨场景行：收藏星 + 变量徽标 + 标签 + 使用次数 + 复制）；`promptCardHtml`（场景详情卡片）。
- `bindCopyButtons`：内容缓存 500 条上限，**未命中时回源 RPC `getPrompt` 拉取**，杜绝静默复制空内容。
- `bindFavoriteStars`：星标就地更新所有同 id 星标；成功后广播 `prompt-favorite-changed` DOM 自定义事件（全部提示词页的"仅收藏"筛选据此联动刷新，事件解耦避免循环导入）。

### 4.4 命令面板（command.ts）
- `Ctrl/⌘+K` 唤起；150ms 防抖；**递增序号竞态守卫**（`refreshSeq`）——快速连续输入时丢弃过期响应，面板关闭使在途响应失效。
- 结果分组各限 6 条；`<mark>` 高亮（先转义再匹配防注入）；空查询显示最近使用 5 条。

### 4.5 提示词详情页（prompts.ts）
- 变量填充面板实时联动编辑器；`Ctrl/⌘+S` 模块级单例 handler（防叠加，页面离开自动失效）；**保存防重复提交**（`savingPrompt` 标志统一防护按钮与快捷键）。
- 渲染竞态守卫：await 后校验 `state.view` **且 `state.promptId`** 未变（快速从提示词 A 直达 B 时旧渲染被放弃）；场景详情同构守卫 `scenarioId`。
- 预检：变量未填齐阻止提交；运行期间按钮禁用；错误输出以 `[Error]` 前缀识别并 Toast。
- 版本恢复后同步刷新变量面板；删除 = 软删除 + 确认框。

### 4.6 视图切换与局部刷新
- 导航过渡：130ms 淡出 → 替换 → 淡入，`transitionToken` 防连点交叠。
- 全部提示词：排序/标签/收藏切换仅刷新列表区域，`refreshToken` 丢弃过期响应。
- **懒加载分页**（`allprompts.ts`）：首屏 `PAGE_SIZE = 6` 条，**不做任何自动补齐**——续载完全由用户动作驱动：有滚动条时滚到距底部 60px 内续载（scroll 事件），两次续载间 500ms 冷却（一次滚动手势 ≈ 一页）；内容不足一屏、没有滚动条时，滚轮向下触发下一页。页脚显示"已显示 x / y 条"进度（同时是分页是否生效的直观诊断），加载完毕显示"已全部加载"，失败 2s 自动重试同一页；`activeLoad` 在途令牌防重复触发；追加行在临时容器内完成事件绑定后搬入（防重复绑定）；页头计数恒为 `total`（筛选匹配总数）。数据层以 `id DESC` tiebreaker 保证分页顺序确定、不重不漏。
- 启动：`loadAll()` 失败时显示错误态 + "重试"按钮（`location.reload()`），不再永久停留在"加载中"。

### 4.7 弹窗防重复提交
新建场景 / 新建提示词 / 模型配置三处模态的保存按钮均在请求期间禁用（校验失败不进入禁用态），杜绝双击重复创建。
